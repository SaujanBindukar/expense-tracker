
# Expenses Tracker

This is a your personal expense tracker application.

# Tech Stack Used:
    1. HTML
    2. CSS
    3. JavaScript
    4. MySQL
    
# Features:
    1. Add Expenses using Category
    2. Update Expenses
    3. Delete Expenses
    4. Adding the budget limit
    5. Category Breakdown and Insights
    6. Expense filter by Month and All time
